# Ferramentas do Gabinete — Câmara de Santos

Conjunto de painéis de transparência e fiscalização do gabinete (Rui de Rosis Jr., PL). A página
inicial (`index.html`) é um **hub** que reúne os bancos pesquisáveis — **Despesas**, **Proposituras**,
**Legislação**, **Requerimentos & Respostas** e **Regimento Interno**. Veja o `CLAUDE.md` para a
visão completa das aplicações e automações (Briefing Ordem do Dia, Respostas do Executivo,
Monitor do Diário Oficial).

Publicado em: https://derosisjr.github.io/Playground/
